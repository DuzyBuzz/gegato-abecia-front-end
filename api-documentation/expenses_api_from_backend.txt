Main Address : /expenses
All date variables: YYYY-mm-dd

Call /expenses/find/1/500 for sample definition



Finding Data:
/find/{page}/{limit}
/find_record/{id}
/find_by_receipt_date/{startDate}/{endDate} 
/find_by_entry_date/{startDate}/{endDate}
/find_by_category/{category}
/find_by_category_sub/{categorySub}
/find_by_particular/{filter} - filter can be partial

CRUD:
/delete/{id}
/save
Notes:
Accepts a list. Encapsulate data in a list/array if saving only 1
Returns the list of data with created id along with usual 100/200 response

/categories/find/{id}
Notes:
0 - finds all category
Non Zero - find by id
Calls categories with their subcategories

CRUD:
/categories/delete_category/{id}
/categories/save_categories
Notes:
Accepts a list. Encapsulate data in a list/array if saving only 1
Will save both category and sub-category attach 0 on id if new data
Returns the list of data with created id along with usual 100/200 response

Assuming your API root is:

```text
https://gegato-abecia-fh.appspot.com
```

Here are the Postman requests you can use.

---

# 1. Find Expenses (Paginated)

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find/1/500
```

---

# 2. Find Expense by ID

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_record/1
```

Replace `1` with the actual expense ID.

---

# 3. Find by Receipt Date

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_by_receipt_date/2026-01-01/2026-01-31
```

---

# 4. Find by Entry Date

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_by_entry_date/2026-01-01/2026-01-31
```

---

# 5. Find by Category

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_by_category/Office Supplies
```

If category contains spaces:

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_by_category/Office%20Supplies
```

# 7. Find by Particular (Partial Search)

### GET

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find_by_particular/ink
```

---

# 8. Delete Expense

### DELETE

```http
DELETE https://gegato-abecia-fh.appspot.com/expenses/delete/1
```

Replace `1` with the expense ID.

---

# 9. Save Expense

### POST

```http
POST https://gegato-abecia-fh.appspot.com/expenses/save
```

### Headers

```json
Content-Type: application/json
```

### Body (raw JSON)

Since the API requires a LIST:

```json
[
  {
    "id": 0,
    "receiptDate": "2026-06-01",
    "entryDate": "2026-06-01",
    "category": "Office Supplies",
    "categorySub": "Paper",
    "particular": "A4 Bond Paper",
    "amount": 500
  }
]
```

> The actual field names may differ. Call `/expenses/find/1/500` first and copy the exact JSON structure returned by the API.

# Fastest way to discover the exact schema

Run this first:

```http
GET https://gegato-abecia-fh.appspot.com/expenses/find/1/1
```

and

```http
GET https://gegato-abecia-fh.appspot.com/expenses/categories/find/0
```

Then copy the returned JSON and use the exact property names when testing the POST endpoints. This avoids guessing field names and immediately reveals the correct request payload format.
